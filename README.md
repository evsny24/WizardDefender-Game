# Wizard Defender

**Wizard Defender** is my very first independently developed video game. This project is fully open source and available on GitHub. I created it solo over a summer a few years ago to experience and learn the full process of game development. The game is written in **GDScript**, Godot's scripting language, which is very similar to Python.

---

## Overview

This project was designed as a learning experience to understand the workflow of game development from idea to execution. The game is a top-down action experience where the player fights against waves of enemies and faces a boss dragon with minions.

---

## Development Journey

### 1. Planning & Asset Sourcing
- Brainstormed ideas for gameplay, features, assets, and sound.
- Searched for and used **free-to-use assets and sound effects** to respect copyright laws.
- Focused on **good development habits** from the very beginning.

### 2. Building Gameplay
- Learned Godot’s interface to **import assets, create scripts, and implement hitboxes**.
- Added physics to projectiles and **collision detection** between characters and projectiles.
- Developed the core **gameplay loop** with functional combat mechanics.

### 3. Scenes & User Interface
- Implemented **multiple scenes** for different purposes:
  - Main menu with options to Play, View Directions, and Change Settings.
  - Settings menu with adjustable **audio options**.
- Added **sound effects and music** for immersive gameplay.

### 4. Playtesting & Balancing
- Conducted playtesting to adjust difficulty.
- Added a **player power-up** to make gameplay more manageable.
- Final game includes a **boss fight against a dragon and its minions**.
